## 🌟 نظرة عامة (Overview)

فيرموير متكامل وعالي الأداء لنواة **ESP32-C5 Mini** أحادية النواة (32-bit RISC-V بسرعة تصل إلى 240 ميجاهرتز)، يحوّل الشريحة إلى **راوتر وموزع شبكة NAPT متطور ثنائي التردد (2.4GHz & 5GHz)** بتقنية **Wi-Fi 6 (802.11ax)**.

يحتوي المشروع على واجهة ويب تحكم مدمجة بنسبة **1:1** (`Single Page Application`) مخزنة ومضغوطة بصيغة Gzip داخل الذاكرة الفلاشية، بتصميم زجاجي عصري (`Glassmorphism`)، تدعم الوضع الليلي الكوني (`Sunset`) والوضع السيبراني (`Matrix`)، مع تحكم فائق بالسرعة والحصص (Quota) وبوت تيليجرام تفاعلي ونظام تحديث هوائي مزدوج (Dual-Bank OTA).

## ⚡ المواصفات التقنية الفائقة (Key Features)

### 1. عتاد النواة والشبكة (Hardware & Wi-Fi Subsystem)
* **المعالج:** 32-bit RISC-V Single-Core يعمل بتردد **240 MHz** (مع دعم أوضاع الطاقة `240MHz Max Performance`, `160MHz Balanced`, `80MHz Eco`).
* **دعم Wi-Fi 6 ثنائي التردد:** 
  * تردد **2.4 GHz** (`802.11b/g/n/ax`).
  * تردد **5 GHz** (`802.11a/n/ac/ax` - قنوات U-NII من 36 حتى 165).
  * قنوات عريضة `HE40` و `HT40` لأعلى معدل نقل بيانات.
* **توجيه الحزم lwIP NAPT:** توجيه مباشر لحزم IPv4 على مستوى النواة مع جدول NAPT يتسع لـ 1024 منفذ متزامن.
* **محدد سرعة فائق الدقة (IRAM Token Bucket):** خطاف شبكي (`netif input hook`) يعمل بالكامل داخل ذاكرة **IRAM** السريعة لتطبيق حدود التحميل والرفع لكل جهاز بدون أي تأخير (`Latency-free`).
* **وضع الألعاب الفائق (VIP Gaming Mode):** يمنح الأولوية القصوى لحزم ألعاب الفيديو عبر وسوم `DSCP 46 (Expedited Forwarding)` وتجاوز طوابير الخنق.

### 2. لوحة التحكم الزجاجية المدمجة (SPA Dashboard)
* **واجهة عربية احترافية بالكامل (RTL):** مع شريط تحكم بتكبير/تصغير الشاشة (`Zoom Capsule` من 70% إلى 110%).
* **ثيمات مزدوجة:** ثيم الغروب الكوني (`Sunset Theme`) وثيم الماتريكس السيبراني (`Cyber Matrix Theme`).
* **شريط إحصائيات حي (7 بطاقات مدمجة):** سرعة التحميل والرفع اللحظية، الأجهزة المتصلة، استهلاك باقة الإنترنت، الذاكرة الحرة (Heap RAM)، وقت التشغيل، وتردد الشبكة.
* **أرصفة عائمة ذكية (Dual Floating Docks):** رصيف أيسر للإحصائيات الحية ورصيف أيمن للتنقل السريع بين الأقسام.
* **رسم بياني حي (Live Throughput Canvas Chart):** منحنيات بيانية مزدوجة لحركة مرور البيانات تتحدث كل ثانيتين.
* **نظام صلاحيات وجلسات آمن (RBAC Auth):** مصادقة بجلسة `session_id` مع كلمة مرور مشفرة بـ SHA-256 وزر فيزيائي لاستعادة ضبط المصنع (GPIO9).

### 3. الأقسام والوظائف (Modules & Tabs)
1. **👥 إدارة الأجهزة وسرعاتها:**
   - عرض شبكي (Cards) وجدولي (Table).
   - تحديد سقف التحميل (`Down Cap`) وسقف الرفع (`Up Cap`) لكل جهاز بـ Mbps.
   - تحديد سقف الاستهلاك (`Quota GB`) لكل جهاز مع الحظر التلقائي فور النفاذ.
   - قسم خاص بالأجهزة غير المتصلة (Offline History) لضبط الإعدادات مسبقاً أو مسح السجل.
2. **🎯 باقة الإنترنت ومعايرة العداد:**
   - ضبط سعة الباقة وتاريخ البدء والتجديد مع نسبة الاستهلاك والمتبقي.
   - معايرة دقة العداد (`Meter Scale` من 50% إلى 110%).
   - التبديل بين معيار البايت الثنائي (`1024MB = 1GiB`) والعشري (`1000MB = 1GB`).
3. **🤖 بوت تيليجرام التفاعلي (HTTPS Long-Polling):**
   - إشعارات فورية عند بلوغ نسب استهلاك محددة (مثل: 50%، 75%، 90%، 95%).
   - تحكم كامل بالراوتر عبر الرسائل: `/quota`, `/devices`, `/speed`, `/block`, `/unblock`, `/status`, `/ota`, `/reboot`.
   - كونسول محاكاة تفاعلي داخل لوحة التحكم.
4. **📊 المراقبة وإعادة التشغيل المجدول:**
   - فحص قوة الإشارة ومراقبة حالة الشبكة الأم.
   - جدولة إعادة التشغيل اليومي في وقت محدد مع مزامنة الوقت عبر بروتوكول SNTP.
   - حفظ تلقائي للعدادات في ذاكرة NVS قبل إعادة التشغيل وإرسال تقرير إقلاع للتيليجرام.
5. **⚙️ إعدادات شبكة الواي فاي وثنائي التردد:**
   - ماسح شبكات Dual-Band حي لكشف شبكات 2.4GHz و 5GHz مع قنواتها.
   - ربط الراوتر بالشبكة المزودة (WAN STA) وضبط شبكة التوزيع (SoftAP) بأسماء وتشفير WPA2/WPA3.
6. **🚀 التحديث الهوائي وحماية النظام (Dual-Bank OTA):**
   - بنية تقسيم فلاشية مزدوجة (`ota_0` و `ota_1`) بحجم 1.85 ميجابايت لكل منها.
   - ميزة التراجع التلقائي (`Anti-Rollback`) في حال فشل تشغيل التحديث الجديد.
   - دعم التحديث عبر رفع ملف الفيرموير أو عبر رابط مباشر (URL OTA).

## 🚀 طريقة التجميع والرفع (Building & Flashing)

### 1. المتطلبات (Prerequisites)
* تثبيت بيئة **ESP-IDF v5.3+** أو **v6.x**.
* لوحة تطوير **ESP32-C5 Mini** موصولة بجهاز الكمبيوتر عبر منفذ USB.

### 2. التجميع والبرمجة (Commands)

افتح موجه أوامر ESP-IDF ونفّذ التالي:

```bash
# الدخول إلى مجلد المشروع
cd esp32c5-pro-router

# تحديد الهدف كـ ESP32-C5
idf.py set-target esp32c5

# بناء الفيرموير بالكامل
idf.py build

# حرق الفيرموير على الشريحة ومراقبة السيريال (استبدل COM_PORT برقم المنفذ لديك)
idf.py -p COM_PORT flash monitor
```

## 🔑 تسجيل الدخول واستعادة ضبط المصنع

* **الشبكة الافتراضية بعد الإقلاع:**
  * **SSID:** `ESP32-C5-5G-Router`
  * **Password:** `12345678`
  * **IP Address:** `192.168.4.1`
* **بيانات دخول لوحة التحكم:**
  * **اسم المستخدم:** `admin`
  * **كلمة المرور الافتراضية:** `admin`
* **استعادة ضبط المصنع فيزيائياً (Factory Reset):**
  * اضغط باستمرار على زر **BOOT / GPIO9** لمدة **10 ثوانٍ**.
  * سيقوم الراوتر بمسح كافة إعدادات NVS، وتصفير كلمة المرور إلى الافتراضية، ثم إعادة الإقلاع تلقائياً.
